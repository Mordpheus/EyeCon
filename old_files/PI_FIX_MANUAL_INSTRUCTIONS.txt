# Manual UVC-Gadget Fix Instructions
## For Direct Pi Execution

Execute these commands one-by-one on the Raspberry Pi (via SSH or physical access):

```bash
# Step 1: Stop the service
sudo systemctl stop uvc-gadget.service

# Step 2: Wait 2 seconds
sleep 2

# Step 3: Remove the old gadget configuration
sudo rm -rf /sys/kernel/config/usb_gadget/g1

# Step 4: Reload the USB device controller
sudo modprobe -r dwc2
sleep 1
sudo modprobe dwc2

# Step 5: Start service fresh
sudo systemctl start uvc-gadget.service
sleep 2

# Step 6: Verify it worked
systemctl status uvc-gadget.service
vcgencmd get_camera
```

### Expected Output

After running `vcgencmd get_camera`, you should see:
```
supported=1 detected=1
```

If you see `supported=1 detected=1` → SUCCESS! The fix worked.

### If It Still Doesn't Work

Run this diagnostic:
```bash
sudo journalctl -u uvc-gadget.service -n 30
ls -la /sys/kernel/config/usb_gadget/
lsmod | grep uvc
```

Then send the output to the development team.

### One-Liner (Copy & Paste)
If you want to run it all at once:
```bash
sudo systemctl stop uvc-gadget.service && sudo rm -rf /sys/kernel/config/usb_gadget/g1 && sudo modprobe -r dwc2 && sleep 1 && sudo modprobe dwc2 && sudo systemctl start uvc-gadget.service && sleep 2 && vcgencmd get_camera
```

---

**Note:** The USB device stack will briefly disconnect/reconnect during the `modprobe` commands. This is normal and expected.
